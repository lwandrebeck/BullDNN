# Per-group symmetric INT8 MoE — non-fused expert GEMMs (no GGML).
#
# Exercises the N-tile (ALGO 3) per-group DQ-INT8 path on the AOCL DLP
# backend: bf16 activations, s8 weights carrying a per-group {G, N} f32
# scale (G = K / group_size groups), and a {M, G} src scale that the
# library's pre-OMP hoist fills by quantizing the bf16 src per-group at
# call time.  Most experts run one plain GEMM (gated_act=0) plus the fused
# MoE weighted-reduce (moe_topk); the final section additionally exercises
# the GATED gate+up projection (gated_act>0, N = 2*intermediate).
#
# Column layout (16 fields; per-group needs every optional column filled
# up to group_size):
#   num_ops, M, K, N, iters, src_dt:wei_dt:dst_dt, is_weights_const, warmup,
#     moe_topk, gated_act, N_down, use_internal_alloc, total_experts,
#     dynamic_quant, compute_dt, group_size
#
# Fixed for every line below: bf16:s8:bf16, dynamic_quant=1, compute_dt=s8
# (per-group is symmetric-only), N_down=0 (non-fused), use_internal_alloc=0.
# gated_act=0 except the final "gated gate+up" section (silu_and_mul=1,
# swiglu_oai_mul=3).  group_size divides K, 0 < group_size < K, K%gs==0.
#

# Gated gate+up projection — mirrors a real fused MoE gate/up.
# The gate+up GEMM emits N = 2*intermediate columns (gate|up concatenated);
# a gated activation collapses them to [M, intermediate], then the down
# projection maps back to hidden.  Still one per-group symmetric int8 DLP
# call per expert — the {G, N} wei scale spans the full gate|up width, and
# the activation runs as the epilogue post-op (not the fused Op1→Op2 path,
# so N_down stays 0).
#   gate+up: gated_act > 0, N = 2*intermediate     down: gated_act = 0
#   silu_and_mul=1 (Mixtral / Qwen3),  swiglu_oai_mul=3 (GPT-OSS)
# ═══════════════════════════════════════════════════════════════════════
